HTML: Structuring the Web

HTML (HyperText Markup Language) uses "tags" (elements enclosed in angle brackets < >) to define the structure and meaning of content on a webpage. Most tags come in pairs: an opening tag (e.g., <p>) and a closing tag (e.g., </p>).

Basic Document Structure

Every HTML document follows this fundamental structure:


<!-- Declares the document type (HTML5) -->
<!DOCTYPE html>

<!-- The root element, language attribute is important -->
<html lang="en">

  <!-- Head contains meta-information (not displayed) -->
  <head>
    <meta charset="UTF-8"> <!-- Character encoding -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0"> <!-- For responsive design -->
    <title>Page Title</title> <!-- Shows in browser tab -->
    <link rel="stylesheet" href="css/style.css"> <!-- Link to CSS -->
  </head>

  <!-- Body contains the visible page content -->
  <body>
    <h1>Main Heading</h1>
    <p>This is a paragraph.</p>
  </body>

</html>

Common Tags & Elements

Text Content

  • <h1> to <h6>: Headings, defining importance hierarchy.
  • <p>: Paragraphs.
  • <a href="...">Text</a>: Anchor tag for hyperlinks. href specifies the URL.
  • <strong> or <b>: Bold/Strong importance text. (<strong> is preferred for semantic importance).
  • <em> or <i>: Emphasized/Italic text. (<em> is preferred for semantic emphasis).
  • <span>: Generic inline container, useful for styling parts of text without adding semantic meaning.
  • <br>: Line break (use sparingly; prefer CSS margins/padding for spacing).
  • <hr>: Thematic break (horizontal rule), represents a paragraph-level thematic break.
  • <ul>, <ol>, <li>: Unordered (bullet) lists, Ordered (numbered) lists, and List Items.
  • <dl>, &dt>, <dd>: Description lists, terms, and descriptions.
  • <blockquote>: For long quotations, often indented by browsers.
  • <code>: For inline code snippets.
  • <pre>: For preformatted text blocks (preserves whitespace, often used with <code> inside).

Grouping & Structure (Semantic HTML)

Semantic tags describe their content's meaning, improving accessibility (for screen readers) and SEO (for search engines).

  • <div>: Generic block-level container (use when no other semantic tag fits, primarily for styling/layout).
  • <header>: Introductory content for a page or section (logos, navigation, headings, search forms).
  • <nav>: Container for major navigation links.
  • <main>: The main, unique content of the page (should only be one per page).
  • <article>: Self-contained, independently distributable content (e.g., blog post, news story, forum post).
  • <section>: A thematic grouping of content, typically with a heading. Don't use it as a generic container like <div>.
  • <aside>: Secondary content, often tangential to the main content (e.g., sidebars, pull quotes, related links).
  • <footer>: Footer content for a page or section (copyright, contact info, related documents links).
  • <figure> & <figcaption>: For embedding images, diagrams, code blocks, etc., with an optional caption (<figcaption>).
  • <address>: Contact information for the nearest ancestor <article> or <body>.

Media

  • <img src="..." alt="..." width="..." height="..." loading="lazy">: Embeds images. `loading="lazy"` added for performance.
  • <audio controls src="...">...</audio>
  • <video controls src="..." width="..." height="...">...</video>
  • <picture> with <source> tags for responsive images.

Forms

Forms allow users to input data.

  • <form>, <label>, <input> (various types), <textarea>, <select>, <option>, <button>, <fieldset>, <legend>.
  • Key attributes: action, method, for, id, name, type, value, placeholder, required.

Tables

Used for displaying tabular data.

  • <table>, <caption>, <thead>, <tbody>, <tfoot>, <tr>, <th> (with scope attribute), <td>.
  • Attributes: colspan, rowspan.

Attributes

Attributes provide additional information about elements.

  • Global: id, class, style, title, lang, tabindex, data-*, hidden.
  • Specific: href (a), src/alt (img), type/value (input), etc.

HTML Example


<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>HTML Example Page</title>
    <link rel="stylesheet" href="css/style.css">
</head>
<body>
    <header>
        <h1 id="main-heading">HTML Introduction</h1>
        <nav aria-label="Main navigation">
            <ul>
                <li><a href="#basics">Basics</a></li>
                <li><a href="#forms">Forms</a></li>
            </ul>
        </nav>
    </header>

    <main>
        <section id="basics" aria-labelledby="basics-heading">
            <h2 id="basics-heading">Basic Elements</h2>
            <p>This page demonstrates various HTML elements.</p>
            <figure>
              <img src="https://placehold.co/200x100/a0aec0/ffffff?text=HTML+Image" alt="Placeholder image" width="200" height="100" loading="lazy">
              <figcaption>A placeholder image.</figcaption>
            </figure>
        </section>

        <section id="forms" aria-labelledby="forms-heading">
            <h2 id="forms-heading">Example Form</h2>
            <form action="/submit-data" method="post">
                <div>
                  <label for="username">Username:</label>
                  <input type="text" id="username" name="user_name" required>
                </div>
                <button type="submit">Submit</button>
            </form>
        </section>
    </main>

    <footer>
        <p>© 2025 Discite Learning</p>
    </footer>
</body>
</html>
