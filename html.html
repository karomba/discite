HTML: Structuring the Web 🏗️

HTML (HyperText Markup Language) uses "tags" (like <p>) to structure content. Think of it as the blueprint for your webpage. Most tags have an opener and a closer (<p>...</p>).

Basic Document Structure 뼈대

Every HTML page needs this basic setup:


<!-- Tells the browser it's HTML5 -->
<!DOCTYPE html>

<!-- Root element (speaks English) -->
<html lang="en">

  <!-- Head: Stuff for the browser (invisible stuff) -->
  <head>
    <meta charset="UTF-8"> <!-- Handles text characters correctly -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0"> <!-- Makes it mobile-friendly -->
    <title>Page Title ✨</title> <!-- Shows in the browser tab -->
    <link rel="stylesheet" href="css/style.css"> <!-- Links your CSS styles -->
  </head>

  <!-- Body: The actual visible content 🤩 -->
  <body>
    <h1>Main Heading</h1>
    <p>This is a paragraph.</p>
  </body>

</html>

Common Tags & Elements 👇

Text Content ✍️

  • <h1> to <h6>: Headings (Big important text to less important).
  • <p>: Paragraphs (Just normal text blocks).
  • <a href="...">Link Text</a>: Links to other pages or sites 🔗.
  • <strong> / <b>: **Bold** text (strong means it's important).
  • <em> / <i>: *Italic* text (em means emphasis).
  • <span>: For styling small bits of text inline.
  • <br>: Line break (use sparingly!).
  • <hr>: Horizontal line (like a divider).
  • <ul> (bullets ⚫️), <ol> (numbers 🔢), <li> (list items).
  • <blockquote>: For quoting someone famous (or not 😉).
  • <code>: For showing `inline code`.
  • <pre>: For blocks of code (keeps spacing!).

Grouping & Structure (Semantic HTML) 🧱

Use tags that describe the content's purpose (good for SEO & accessibility ✅).

  • <div>: Generic box (use when nothing else fits).
  • <header>: Top intro part (logo, nav).
  • <nav>: Main navigation links area.
  • <main>: The main content, unique to the page.
  • <article>: A self-contained piece (blog post, etc.).
  • <section>: A themed group of content.
  • <aside>: Sidebar-ish content.
  • <footer>: Bottom stuff (copyright, etc.).
  • <figure> & <figcaption>: Image/diagram with a caption.

Media 🖼️🎵🎬

  • <img src="..." alt="..." width="..." height="..." loading="lazy">: Images! `alt` text is super important for accessibility. `loading="lazy"` helps speed things up.
  • <audio controls src="...">...</audio>: Sound player.
  • <video controls src="..." ...>...</video>: Video player.
  • <picture>: For fancy responsive images.

Forms 📝

Let users type stuff in.

  • <form>, <label>, <input> (text, password, email, checkbox, radio, submit, etc.), <textarea>, <select>, <button>.

Tables 📊

For showing data in rows & columns.

  • <table>, <thead>, <tbody>, <tr>, <th>, <td>.

Attributes ✨

Extra info added to tags (name="value").

  • Global: id (unique!), class (reusable style group), style (inline CSS - avoid mostly), title (tooltip), lang, data-* (custom data).
  • Specific: href, src, alt, type, value, placeholder, required.

HTML Example 📋


<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>HTML Example Page</title>
    <link rel="stylesheet" href="css/style.css">
</head>
<body>
    <header>
        <h1 id="main-heading">HTML Intro ✨</h1>
        <nav aria-label="Main navigation">
            <ul>
                <li><a href="#basics">Basics</a></li>
                <li><a href="#forms">Forms</a></li>
            </ul>
        </nav>
    </header>

    <main>
        <section id="basics" aria-labelledby="basics-heading">
            <h2 id="basics-heading">Basic Elements 👇</h2>
            <p>This page shows off different HTML elements.</p>
            <figure>
              <img src="https://placehold.co/200x100/a78bfa/ffffff?text=HTML+Image+%F0%9F%96%BC%EF%B8%8F" alt="Placeholder image" width="200" height="100" loading="lazy">
              <figcaption>A placeholder image example.</figcaption>
            </figure>
        </section>

        <section id="forms" aria-labelledby="forms-heading">
            <h2 id="forms-heading">Example Form 📝</h2>
            <form action="/submit-data" method="post">
                <div>
                  <label for="username">Username:</label>
                  <input type="text" id="username" name="user_name" required>
                </div>
                <button type="submit">Submit ✅</button>
            </form>
        </section>
    </main>

    <footer>
        <p>© 2025 Discite Learning</p>
    </footer>
</body>
</html>
