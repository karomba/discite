CSS: Styling the Web 🎨

CSS (Cascading Style Sheets) is how you make your HTML look good. It controls colors, fonts, layout, spacing – basically the whole vibe ✨.

Including CSS 🔌

Three ways to add styles:

  • External Stylesheet (Best! 👍): Link a .css file in <head>. Keeps things tidy.
  • Internal Stylesheet: Use <style> tags in <head>. Okay for small stuff.
  • Inline Styles: style="..." attribute on elements (Avoid if possible 🙅‍♀️).

CSS Rule Structure 📜

It's like giving instructions:


/* Target something { Tell it what to do; } */
p { /* Select all paragraphs */
  color: purple; /* Make text purple */
  font-size: 1.1rem; /* Make font slightly bigger */
}

Selectors 👉

How you target HTML elements:

  • Type (h1), Class (.cool-button), ID (#main-logo - unique!)
  • Attribute (input[type="checkbox"])
  • Pseudo-classes (:hover, :focus, :nth-child(2) - the second kid)
  • Pseudo-elements (::before, ::after - add little extra bits)
  • Combinators (article p - paragraphs inside articles)

The Cascade, Specificity, and Inheritance 🤔

  • Cascade: Rules flow down, later rules or more specific rules win.
  • Specificity: How specific a selector is (ID > Class > Type). More specific = more power 💪.
  • Inheritance: Some styles (like font, color) flow down to children automatically.
  • !important: Overrides almost everything (use carefully! 🚨).

The Box Model 📦

Every element is a box! It has:

  • Content: The actual stuff.
  • Padding: Space inside the border.
  • Border: The line around the padding.
  • Margin: Space outside the border (pushes other boxes away).

box-sizing: border-box;

Pro tip: Use this so width/height includes padding & border. Makes life easier!


*, *::before, *::after { box-sizing: border-box; }

Layout: Flexbox and Grid 📐

Flexbox 💪

Great for arranging items in a line (row or column).

  • Use display: flex; on the container.
  • Align items with justify-content and align-items.

CSS Grid ▦

Awesome for 2D layouts (rows AND columns).

  • Use display: grid; on the container.
  • Define columns/rows with grid-template-columns/rows.

Units 📏

  • Absolute: px (pixels).
  • Relative: %, em, rem (use `rem` for fonts!), vw/vh (viewport size).

Common Properties (Just a few!) 👇

  • Text: font-family, font-size, color, text-align.
  • Backgrounds: background-color, background-image.
  • Spacing: padding, margin.
  • Size: width, height.
  • Borders: border, border-radius (for rounded corners!).
  • Layout: display (flex, grid, block, inline), position.

Responsive Design & Media Queries 📱💻

Make your site look good everywhere! Use @media to apply styles based on screen size.


/* Default (Mobile) */
.button { width: 100%; }

/* Tablet size and up */
@media (min-width: 768px) {
  .button { width: auto; } /* Becomes normal size */
}
