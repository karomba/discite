CSS: Styling the Web

CSS (Cascading Style Sheets) controls the visual presentation, layout, and appearance of HTML elements. It works by applying style rules (declarations) to selected elements.

Including CSS

There are three ways to add CSS:

  • External Stylesheet (Recommended): Link a .css file in <head>.
  • Internal Stylesheet: Use <style> tags in <head>.
  • Inline Styles: Use the style attribute on elements (least recommended).

CSS Rule Structure


/* Comment */
selector {
  property: value;
}

Selectors

Target HTML elements.

  • Type (h1), Class (.my-class), ID (#my-id)
  • Attribute ([type="text"])
  • Pseudo-classes (:hover, :nth-child())
  • Pseudo-elements (::before, ::first-line)
  • Combinators (descendant , child >, adjacent +, general sibling ~)
  • Grouping (h1, h2 { ... })

The Cascade, Specificity, and Inheritance

  • Cascade: Order of rule application (Origin > Specificity > Source Order).
  • Specificity: How specific a selector is (Inline > ID > Class/Attribute/Pseudo-class > Type/Pseudo-element).
  • Inheritance: Some properties (like color, font-family) are passed down from parent to child.
  • !important: Overrides specificity (use sparingly).

The Box Model

Elements are boxes with Content, Padding, Border, Margin.

box-sizing Property

border-box is recommended (width/height include padding and border).


*, *::before, *::after { box-sizing: border-box; }

Layout: Flexbox and Grid

Flexbox

One-dimensional layout (rows or columns).

  • Container: display: flex;, justify-content, align-items, flex-direction, flex-wrap, gap.
  • Items: flex-grow, flex-shrink, flex-basis, order, align-self.

CSS Grid

Two-dimensional layout (rows and columns).

  • Container: display: grid;, grid-template-columns, grid-template-rows, gap.
  • Items: grid-column, grid-row.

Units

  • Absolute: px.
  • Relative: %, em, rem (recommended for fonts/spacing), vw, vh, fr (Grid).

Common Properties

  • Typography: font-*, line-height, text-*, color.
  • Backgrounds: background-*.
  • Borders: border, border-radius.
  • Sizing/Spacing: width, height, padding, margin.
  • Layout: display, position (static, relative, absolute, fixed, sticky), top/right/bottom/left, z-index, overflow.
  • Effects: opacity, filter, backdrop-filter, transition, animation.

Responsive Design & Media Queries

Adapt layout to different screen sizes using @media rules.


/* Mobile First */
.container { width: 100%; }

@media (min-width: 768px) { /* Tablet and up */
  .container { width: 90%; max-width: 960px; }
}
