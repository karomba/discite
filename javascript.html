JavaScript: Making Web Pages Interactive

JavaScript (JS) brings web pages to life by enabling dynamic content updates, user interaction handling, animations, data fetching, and much more.

Including JavaScript

  • External File (Recommended): <script src="js/main.js" defer></script> usually before </body>.
  • Internal Script: <script>...</script> tags.
  • defer attribute downloads script in parallel, executes after HTML parsing.
  • async attribute downloads in parallel, executes whenever ready (order not guaranteed).

Core Concepts

Variables & Scope

  • Declaration: let (reassignable, block-scoped), const (constant binding, block-scoped), var (avoid, function-scoped).
  • Scope: Global, Module, Function, Block.
  • Hoisting: Declarations moved up, but let/const have Temporal Dead Zone.

Data Types

  • Primitives: string, number, boolean, null, undefined, symbol, bigint.
  • Object: Collections (plain objects, arrays, functions, dates, etc.).

Operators

  • Arithmetic (+,-,*,/,%,**), Assignment (=,+=), Comparison (===,!==,>), Logical (&&,||,!), Ternary (? :), Type (typeof), Spread/Rest (...), Optional Chaining (?.), Nullish Coalescing (??).

Control Flow

  • Conditionals: if/else if/else, switch.
  • Loops: for, for...of (for iterables), for...in (for object keys), while, do...while.
  • Error Handling: try...catch...finally.

Functions

Reusable code blocks.

  • Declaration (function name(){}), Expression (const n = function(){}), Arrow (const n = ()=>{}).
  • Arrow functions have lexical this.
  • Parameters (definition), Arguments (call). Default & Rest parameters.
  • return value.

Arrays

Ordered lists.

  • Creation: []. Access: arr[i]. Length: arr.length.
  • Methods: forEach, map, filter, reduce, find, push/pop, shift/unshift, slice, splice, join, includes.

Objects

Key-value pairs.

  • Creation: {}. Access: obj.key or obj['key'].
  • Methods: Functions as properties. this keyword context.
  • Object.keys/values/entries. Spread syntax {...obj}.

DOM Manipulation

Interacting with HTML structure.

  • Selecting: getElementById, querySelector, querySelectorAll.
  • Traversing: .parentElement, .children, .nextElementSibling.
  • Changing Content: .textContent, .innerHTML.
  • Changing Attributes: .setAttribute(), .getAttribute(), direct properties (img.src).
  • Changing Styles: .style (inline), .classList (add/remove/toggle - preferred).
  • Creating/Adding/Removing: createElement, append/prepend, remove.

Events & Event Listeners

Responding to user actions.

  • Attaching: element.addEventListener('eventName', handlerFn).
  • Common Events: click, keydown, submit, load, DOMContentLoaded, change, input, mouseover.
  • Event Object: Contains details (event.target), methods (event.preventDefault()).

Interactive Demo

Enter some text and click the button or press Enter.

Output will appear here...

// JS for the demo above (in js/main.js)
const input = document.querySelector('#demo-input');
const button = document.querySelector('#demo-action-button');
const output = document.querySelector('#demo-output');

function updateOutput() {
  const text = input.value.trim();
  output.textContent = text ? `You entered: "${text}"` : 'Please enter text!';
  input.value = '';
  input.focus();
}

if (button) button.addEventListener('click', updateOutput);
if (input) input.addEventListener('keydown', (e) => {
    if (e.key === 'Enter') updateOutput();
});

Asynchronous JavaScript

Handling operations that take time.

  • Callbacks, Promises (.then/.catch), async/await (modern standard).
  • Fetch API for network requests.

// Example async/await with Fetch
async function getUser(id) {
  try {
    const response = await fetch(`https://jsonplaceholder.typicode.com/users/${id}`);
    if (!response.ok) throw new Error(response.statusText);
    const user = await response.json();
    console.log(user);
  } catch (error) {
    console.error('Fetch failed:', error);
  }
}
// getUser(1);
