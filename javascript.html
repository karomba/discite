JavaScript: Making Web Pages Interactive ✨🧠

JavaScript (JS) is the programming language that lets you add dynamic behavior, handle user actions, fetch data, and basically make your website *do* things.

Including JavaScript 🔌

  • Best way: External .js file linked with <script src="script.js" defer></script> before </body>.
  • Okay way: Internal <script>...</script> tags.

Core Concepts 💡

Variables & Scope 📦

  • let name = "Val"; (Can change later).
  • const score = 100; (Cannot be reassigned - use this often!).
  • Scope = Where variables live (Global, Function, Block). let/const are block-scoped.

Data Types 🧱

  • Primitives: string ("text"), number (123, 3.14), boolean (true/false ✅❌), null, undefined.
  • Object: Everything else (arrays [], objects {}, functions).

Operators 🧮

  • Math: + - * / %
  • Comparison: === (strict equals - use this!), !==, >, <
  • Logical: && (AND), || (OR), ! (NOT)

Control Flow 🚦

  • Conditionals: if/else if/else, switch.
  • Loops: for, while, for...of (great for arrays!).
  • Error Handling: try...catch.

Functions ⚙️

Reusable code blocks.

  • Define with function name() {} or const name = () => {} (Arrow function).
  • Arrow functions are often shorter and handle this differently.
  • Can take inputs (parameters) and give back outputs (return value).

Arrays 📋

Ordered lists: [ "🍎", "🍌", "🍒" ]

  • Access items by index: myArray[0] (first item).
  • Useful methods: .forEach(), .map(), .filter(), .find(), .push() (add to end), .pop() (remove from end).

Objects 🔑

Key-value pairs: { name: "Discite", type: "Website" }

  • Access values: myObject.name or myObject['type'].
  • Store data and related functions (methods).

DOM Manipulation 🌳➡️🔧

Changing the HTML page with JS.

  • Select elements: document.querySelector('.my-class'), document.getElementById('my-id').
  • Change text: element.textContent = "New text!".
  • Change styles: element.classList.add('active'), element.style.color = 'red'.
  • Create/Add: document.createElement('div'), parentElement.append(newElement).
  • Remove: element.remove().

Events & Event Listeners 🖱️⌨️

Reacting to user actions.

  • Listen for events: button.addEventListener('click', handleClickFn);
  • Common events: click, keydown (key press), submit (form), mouseover.
  • Handler function gets an `event` object with info (like event.target).

// JS for the demo above (in js/main.js)
const input = document.querySelector('#demo-input');
const button = document.querySelector('#demo-action-button');
const output = document.querySelector('#demo-output');

function updateOutput() {
  const text = input.value.trim();
  // Use a ternary for cleaner conditional text 😎
  output.textContent = text ? `You entered: "${text}"` : 'Bruh, enter something! 🤷';
  output.style.color = text ? '#1e3a8a' : '#b91c1c';
  input.value = '';
  input.focus();
}

// Add listeners only if elements exist
if (button) button.addEventListener('click', updateOutput);
if (input) input.addEventListener('keydown', (e) => {
    if (e.key === 'Enter') {
        e.preventDefault(); // Stop default form submit if any
        updateOutput();
    }
});

Asynchronous JavaScript ⏳

Handling things that take time (like fetching data from the internet 🌐).

  • Callbacks (old way), Promises (better), async/await (modern & clean ✨).
  • Fetch API: The standard way to make network requests.

// Example async/await with Fetch
async function getUserData(userId) {
  const apiUrl = `https://jsonplaceholder.typicode.com/users/${userId}`;
  console.log(`Fetching user ${userId}...`);
  try {
    const response = await fetch(apiUrl);
    if (!response.ok) { // Check for HTTP errors (like 404)
      throw new Error(`HTTP Error: ${response.status}`);
    }
    const user = await response.json(); // Get the data
    console.log('Got user:', user.name, '🎉');
  } catch (error) { // Catch fetch errors OR HTTP errors
    console.error('Failed to fetch user:', error);
  }
}
// Try calling it from the browser console: getUserData(1)
